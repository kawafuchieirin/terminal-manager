# README.md 自動更新ルール

設定ファイルやスクリプトを変更した場合、README.md を以下の構成で最新化すること。

## 更新手順

1. 変更されたファイルの内容を読み取る
2. README.md の該当セクションを実態に合わせて更新する
3. 存在しない機能は削除し、新規追加された機能はセクションに反映する

## README.md の構成（この順序を維持）

1. **タイトル・概要**: プロジェクトの一行説明
2. **セットアップ**: `setup.sh` の実行方法と前提条件（Homebrew等）
3. **構成**: ディレクトリ・ファイル一覧テーブル（実際のファイル構造と一致させる）
4. **各ツールの設定内容**: WezTerm / Zsh / Starship それぞれの主要な設定を簡潔に記載
   - WezTerm: 外観・挙動の設定（最小構成。デフォルト寄り）
   - Zsh: プラグイン、キーバインド、エイリアス一覧、hidden/ の仕組み
   - Starship: プロンプトカスタマイズ内容
5. **設計方針**: ポータビリティ・環境固有設定の分離

## 注意事項

- エイリアス一覧は `zsh/aliases.zsh` の実際の内容からテーブルを生成する
- `setup.sh` でインストールされるパッケージ一覧は実際のスクリプトと一致させる
- WezTerm 設定は `wezterm/wezterm.lua` の実際の内容と一致させる
- 過度に冗長にせず、簡潔にまとめる
