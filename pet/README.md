# pet — コマンドスニペットの使い方

「よく使うが覚えきれない」コマンドや、`<param>` で一部だけ差し替えて使いたいコマンドを
登録・呼び出すための仕組み。スニペット本体は本ディレクトリの `snippet.toml`（Git 管理）。

## 仕組み

| ファイル | 役割 | 管理 |
|---------|------|------|
| `pet/snippet.toml` | スニペットの実体 | リポジトリで Git 管理 |
| `~/.config/pet/snippet.toml` | 上記へのシンボリックリンク | `setup.sh` が作成 |
| `~/.config/pet/config.toml` | pet 本体の設定（snippetfile の絶対パス・fzf・nvim 等） | `~` 展開非対応のため `setup.sh` がマシンごとに生成（追跡対象外） |

## 有効化（最初の一度だけ）

```bash
./setup.sh          # pet をインストール + リンク作成 + config.toml 生成
source ~/.zshrc     # もしくはターミナル再起動
```

## 1. 呼び出す（`Ctrl+G`）

プロンプトで **`Ctrl+G`** → fzf 一覧が開く → 絞り込んで Enter。

- 選んだコマンドは **実行されずに入力行へ挿入** される。そのまま編集して `Enter` で実行できる
  （これが「少し変更して使う」用途の中核）。
- 入力途中で `Ctrl+G` を押すと、その文字列で初期フィルタされた状態で開く
  （例: `doc` まで打って `Ctrl+G` → docker 系が絞り込まれる）。
- 一覧は **コマンドが行頭** に表示される（pet 既定の「説明が先頭」だと長い説明でコマンドが
  右端に押し出されて見切れるため、`select.sh` が表示だけ `コマンド #tags  [説明]` の順に並べ替える）。
- 一覧下部のプレビューに選択中スニペットのコマンド全文が折り返し表示される（行頭表示でも
  切れるほど長いコマンドの全体確認用）。`Ctrl+P` でプレビューの表示/非表示を切り替え。

### パラメータ付きスニペット

`ssh <user>@<host>` のように `<...>` を含むスニペットを選ぶと、その箇所が挿入される。
プロンプト上で実際の値に書き換えて Enter。`<port=3000>` のように `=` 付きはデフォルト値の目印。

## 2. 登録する

```bash
pn -t        # 直前に実行したコマンドを取り込んで登録（おすすめ）
pn           # その場で Command / Description を入力して登録
```

（`pn` = `pet new`）。差し替えたい箇所は `<param>` と書いておくと、次回呼び出し時に
プレースホルダになる。

例:
- Command: `kubectl logs -f <pod> -n <namespace=default>`
- Description: `Pod のログを追跡`

## 3. 編集・整理する

```bash
pe           # snippet.toml を nvim で直接編集
```

（`pe` = `pet edit`）。1 エントリの形式:

```toml
[[snippets]]
  description = "説明（fzf の検索対象になる）"
  command = "実行したいコマンド <param>"
  tag = ["docker", "k8s"]
```

## 4. Git で共有する

登録・編集したら通常どおりコミットする（pet 内蔵の Gist 同期は使わず、リポジトリを単一の情報源とする）。

```bash
git add pet/snippet.toml
git commit -m "feat: pet スニペットを追加"
```

別マシンでは `git pull` → `./setup.sh` で同じスニペットが使える。

## エイリアス

| エイリアス | コマンド |
|-----------|---------|
| `pn` | `pet new`（直前のコマンドを登録するなら `pn -t`） |
| `pe` | `pet edit` |

## 使い分けの目安

- **過去に自分が 1 回打ったものを呼び戻す** → `Ctrl+R`（fzf 履歴検索）
- **繰り返し使う・覚えにくい・一部だけ変えたい定型** → `pn` で登録し `Ctrl+G` で呼び出す
